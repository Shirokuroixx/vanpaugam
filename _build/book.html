01 · The book

Sixteen years, one chapter each

The book runs chronologically from 1975 through 1990, with each chapter dedicated to a single year. It treats City Pop as a living timeline: how it emerged, how it shifted, and how its sound spread through artists, producers, fashion, nightlife and design.

Open it anywhere and you find something useful, whether that is a deep cut, an artist you have never heard of, or context that reframes a familiar track. For long-time listeners it brings structure and depth that has never existed in one place. For new listeners it is a guided way into a catalog that can feel overwhelming. For collectors and DJs it is a reference built around real listening culture.

02 · The object

A record shop book

Square like an LP sleeve and bound to last: 8.5 × 8.5 in casewrap hardcover, 208 pages, full-bleed photographs, and a printed obi band. Every edition gets its own band.
